Here is a complete, single-page HTML document for a cosmetic shop's loyalty point system. You can run it directly in your browser. ```html Glow · Cosmetic Loyalty

✨ Glow · points

cosmetic loyalty · by phone number
🔍 retrieve customer points
💄 Enter a phone number to see points
➕ add / update points
``` How the Loyalty Point System Works You can easily manage customer points with two main sections. The page saves all data directly in your browser. · Search for Points: Enter a customer's phone number in the search field to see their current point balance. The result area will show their points or a message if they're not found. · Add or Update Points: Use the form below to add points to a customer's account. If the phone number is new, it creates a new record. If it exists, it adds the points to their total. · Data Persistence: All customer points are saved in your browser's local storage, so your data remains even after you close the page. A few demo records are pre-loaded for you to test with.
