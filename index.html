``` Core Features and How to Use Them You can manage your customer loyalty program with these key actions. · Search & View Points: Enter a phone number in the search field to see a customer's current points. The result area will display their balance or a message if they're not found. · Add or Update Points: Use the form below the search to add points. If the phone number is new, it creates a record. If it exists, it adds to their total. · Deduct or Delete: When a customer is displayed, you'll see two new buttons. Use Deduct Points to subtract a specific amount, or Delete Customer to remove the record entirely after confirmation. · Backup & Restore: The Export Data and Import Data buttons let you save all customer data to a JSON file or restore it from a previous backup.
